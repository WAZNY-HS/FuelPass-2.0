## Adding AI-thread links
Use the conversation's available sharing control to generate a genuine link. Review the shared contents for personal data or material the team should not publish. Test the link from another browser session. If sharing is unavailable, record that limitation and ask the instructor what process evidence they accept; a local transcript is not automatically a shareable conversation link.

Place the same verified links:
1. In the case study's **Project links** section, beside a short explanation of assistance.
2. In this file and the final folder's **06_AI_Threads/AI-thread-links.md**.
3. Optionally on the final presentation's links slide.

Do not insert fabricated ChatGPT URLs, access tokens or private account links. The responsible AI disclosure does not depend on pretending a share link exists.

## Source snapshot
Download the repository through GitHub's Code → Download ZIP after the final documentation changes, or archive the submitted source revision locally. Record the actual commit SHA in the submission index. A repository link and a pinned source snapshot serve different purposes: ongoing access and reproducibility.
